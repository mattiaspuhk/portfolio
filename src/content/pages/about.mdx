## How I use AI

I use AI every day, and what interests me most is where it actually helps people, rather than where it gets added because it's popular.

At GAIA we built both of our AI features so that the person stays in charge. The import suggests how a spreadsheet maps to contacts, and the user checks it record by record. The Intelligence Center can read an organisation's data, but it can't change anything.

I also like being able to show that something helped. When we sped up the Intelligence Center, time to first words went from 27.3 to 12.9 seconds, and each answer got 12% cheaper. My thesis came from the same curiosity. I built an evaluation harness to compare different RAG approaches and see which one really worked best.

In my own coding I use Claude Code with skills, which are short instruction files for tasks I do often, like checking changes against a project's rules. Some of the review happens automatically, and then I go through the code myself. That's how I built this site too.

## Growing up in a digital state

In Estonia you can sign contracts with your ID card, do your taxes online in a few minutes and vote from your laptop. Growing up with that gave me pretty high hopes for what software can do for people.

It's also part of why a friend and I are building an open-source app for people who ride public transport in Tallinn. We've shown the idea to the city's transport board, and we're now talking with them about getting access to rider data.
